# Python Chapter 6 — Practice Set

This repository contains my solutions to the **Python Chapter 6 Practice Set**.

The exercises focus on applying `if`, `elif`, `else`, comparison operators, logical conditions, strings, lists, and conditional decision-making to practical programming problems.

## Questions Covered

### 1. Find the Greatest of Four Numbers

Write a Python program to find the greatest of four numbers entered by the user.

### 2. Student Pass or Fail

Write a Python program to determine whether a student has passed or failed.

The student must satisfy both conditions:

- Total marks must be at least **40%**
- Marks in each subject must be at least **33%**

The program assumes **3 subjects** and takes the marks as input from the user.

### 3. Detect Spam Comments

A spam comment is defined as text containing any of the following keywords or phrases:

- `"Make a lot of money"`
- `"buy now"`
- `"subscribe this"`
- `"click this"`

Write a Python program to detect whether a given comment is spam.

### 4. Check Username Length

Write a Python program to determine whether a given username contains **less than 10 characters**.

### 5. Check Name in a List

Write a Python program to determine whether a given name is present in a list or not.

### 6. Calculate Student Grade

Write a Python program to calculate the grade of a student based on their marks using the following scheme:

| Marks | Grade |
|---|---|
| 90 – 100 | Ex |
| 80 – 90 | A |
| 70 – 80 | B |
| 60 – 70 | C |
| 50 – 60 | D |
| Below 50 | F |

### 7. Check for "Harry" in a Post

Write a Python program to determine whether a given post is talking about **"Harry"** or not.
